## 1. SQL-запрос может быть просто калькулятором

В PostgreSQL можно написать:

```sql
select 2 + 2 as result;
```

Результат:

```text
result
------
4
```

`select` — «выведи». `as result` — имя столбца в результате. Если имя не нужно,
можно писать просто:

```sql
select 2 + 2;
```

Для заданий 4.3–4.5 таблицы не нужны. Мы просто считаем и форматируем значения.

## 2. Строки и склейка

Строка в SQL пишется в одинарных кавычках:

```sql
select '24093';
```

Склеиваются строки оператором `||`, а не плюсом:

```sql
select '5' || '07' as result;
```

Результат:

```text
507
```

`+` в PostgreSQL — это сложение чисел, а не склейка строк.

---

## 3. Приведение типов: `::text` и `::int`

SQL различает числа и строки. Иногда нужно явно сказать, какой тип нужен:

```sql
select 60::text;   -- число 60 превратить в строку '60'
select '37'::int;  -- строку '37' превратить в число 37
```

В заданиях это пригодится, потому что `lpad` работает со строками,
а `extract` возвращает число.

## 4. Дата и время

Дата-время задаётся так:

```sql
timestamp '2026-10-24 09:37'
```

### `to_char`

`to_char` форматирует дату в строку:

```sql
select to_char(timestamp '2026-10-24 09:37', 'DDHH24');
```

Результат:

```text
2409
```

- `DD` — день месяца (24);
- `HH24` — часы в 24-часовом формате (09).

### `extract`

`extract` достаёт отдельную часть даты:

```sql
select extract(minute from timestamp '2026-10-24 09:37');
```

Результат:

```text
37
```

Минуты — это число. Чтобы получить десятки минут, делим на 10 нацело:

```sql
select extract(minute from timestamp '2026-10-24 09:37')::int / 10;
```

Результат:

```text
3
```

Почему `::int`? Потому что `extract` возвращает numeric, а нам нужно
целочисленное деление: 37 / 10 = 3, а не 3.7.

### Собираем ДДЧЧМ

```sql
select to_char(timestamp '2026-10-24 09:37', 'DDHH24')
       || (extract(minute from timestamp '2026-10-24 09:37')::int / 10)::text
       as ddchchm;
```

Что происходит:

1. `to_char(...)` даёт `'2409'`.
2. `extract(...)::int / 10` даёт `3`.
3. `3::text` даёт `'3'`.
4. `'2409' || '3'` даёт `'24093'`.

## 5. `lpad`: добавить нули слева

`lpad(строка, длина, чем_дополнить)` дополняет строку слева до нужной длины.

```sql
select lpad('60', 4, '0');
```

Результат:

```text
0060
```

Почему `'60'`, а не `60`? Потому что `lpad` работает со строками.
Если height — число, пишем `height::text`:

```sql
select lpad(60::text, 4, '0');
```

Ещё примеры:

```sql
select lpad('7', 2, '0');   -- 07
select lpad('5', 3, '0');   -- 005
```

### ВВВВ

```sql
select lpad(60::text, 4, '0') as vvvv;
```

Результат:

```text
0060
```

## 6. `case`: выбор одного из вариантов

`case` — это «если ... то ... иначе ...».

```sql
select case
           when 743 - 750 < 0 then 'отрицательное'
           else 'положительное'
       end as sign;
```

Результат:

```text
отрицательное
```

Можно возвращать не только строки, но и вычисленные значения.

## 7. `abs`: модуль числа

```sql
select abs(-7);
```

Результат:

```text
7
```

`abs(-7)` убирает минус. Это нужно для кодирования отрицательных отклонений.

## 8. Задание 4.5: БББ

Дано давление `743`. Считаем отклонение от 750:

```sql
select 743 - 750;
```

Результат:

```text
-7
```

Правило кодирования:

- если отклонение отрицательное, ставим `5` и две цифры модуля: `-7` → `507`;
- если положительное, пишем три цифры: `7` → `007`.

Разберём по частям:

```sql
select 743 - 750;                          -- -7
select abs(743 - 750);                     -- 7
select lpad(abs(743 - 750)::text, 2, '0'); -- 07
select '5' || lpad(abs(743 - 750)::text, 2, '0'); -- 507
```

Полный запрос с проверкой знака:

```sql
select case
           when 743 - 750 < 0
               then '5' || lpad(abs(743 - 750)::text, 2, '0')
           else lpad((743 - 750)::text, 3, '0')
       end as bbb;
```

Результат:

```text
507
```

## 9. Частые ошибки

1. **Плюс вместо `||`**
   ```sql
   select '5' + '07'; -- ошибка или не то, что нужно
   ```
   Для строк нужен `||`.

2. **`lpad` с числом**
   ```sql
   select lpad(60, 4, '0'); -- может быть ошибка
   ```
   Нужно `60::text`.

3. **Забыли `::int` при делении**
   ```sql
   select 37 / 10; -- 3.7, а не 3
   ```
   Для десятков минут нужно `37::int / 10`.

4. **Двойные кавычки**
   ```sql
   select "24093"; -- это поиск столбца с именем 24093, а не строка
   ```
   Строки — в одинарных кавычках.

5. **Нет `;` в конце**
   В psql/pgAdmin лучше всегда ставить `;`.

## 10. Мини-упражнения

Проверь себя:

```sql
-- 1. Склейка
select '12' || '34';                 -- 1234

-- 2. lpad
select lpad('7', 3, '0');            -- 007

-- 3. Дата
select to_char(timestamp '2026-10-24 09:37', 'DDHH24'); -- 2409

-- 4. Десятки минут
select extract(minute from timestamp '2026-10-24 09:37')::int / 10; -- 3

-- 5. Всё вместе
select to_char(timestamp '2026-10-24 09:37', 'DDHH24')
       || (extract(minute from timestamp '2026-10-24 09:37')::int / 10)::text;
-- 24093

-- 6. БББ для 743
select case
           when 743 - 750 < 0
               then '5' || lpad(abs(743 - 750)::text, 2, '0')
           else lpad((743 - 750)::text, 3, '0')
       end;
-- 507
```
